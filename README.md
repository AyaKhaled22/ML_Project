# Heart Disease Analysis Using Machine Learning

## Project Overview
This project uses the Heart Disease dataset from the UCI Machine Learning Repository.

The project applies three Machine Learning tasks:
- Regression using Linear Regression.
- Classification using Logistic Regression.
- Clustering using K-Means.

## Dataset
The dataset contains 303 records and 14 columns.

Dataset source: [UCI Heart Disease Dataset](https://archive.ics.uci.edu/dataset/45/heart+disease)

## Project Structure
- `data/`: Contains the cleaned dataset.
- `notebooks/`: Contains the Jupyter Notebook with the project code.
- `results/`: Contains visualizations and model results.
- `project_report.pdf`: Contains the final project report.
